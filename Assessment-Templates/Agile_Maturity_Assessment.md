Agile Maturity Assessment Framework v1.0
Purpose

The Agile Maturity Assessment helps organizations evaluate their current Agile capabilities, identify improvement opportunities, and create a roadmap for continuous improvement.

This assessment is intended to be used as a coaching and improvement tool rather than an audit or compliance exercise.
Maturity Scale
| Score | Description      |
| ----- | ---------------- |
| 1     | Initial / Ad-hoc |
| 2     | Emerging         |
| 3     | Defined          |
| 4     | Managed          |
| 5     | Optimizing       |
